# Política de Privacidad

**Última actualización:** 29 de octubre de 2026

Esta Política de Privacidad describe cómo se maneja tu información cuando utilizas la aplicación móvil **Tap And Tap** (en adelante, "la Aplicación"), desarrollada por **Giovanni Arrazola** (en adelante, "el Desarrollador").

## 1. Información que recopilamos

**La Aplicación no recopila, almacena ni comparte ningún dato personal del usuario.**

La Aplicación no requiere registro, inicio de sesión ni creación de cuenta de usuario.

## 2. Uso de los datos

Dado que no se recopila ningún dato personal:
- No se venden datos a terceros.
- No se comparten datos con terceros.
- No se almacenan datos en servidores externos.

## 3. Servicios de terceros

La Aplicación **no utiliza** servicios de análisis, publicidad, seguimiento ni SDK de terceros que recopilen datos personales.

## 4. Privacidad infantil

La Aplicación no recopila intencionadamente información personal de menores de 13 años. Si eres padre o tutor y crees que tu hijo nos ha proporcionado información personal, contacta con nosotros para que podamos tomar las medidas necesarias.

## 5. Seguridad de los datos

Dado que la Aplicación no recopila ningún dato personal, no existe riesgo de acceso no autorizado a datos de usuario.

## 6. Cambios en esta Política de Privacidad

Cualquier cambio en esta Política de Privacidad se publicará en esta misma página con una actualización de la fecha. Se recomienda revisar esta página periódicamente.
